# Контент документации

Исходники страниц документации: Markdown с front-matter в формате
[Starlight](https://starlight.astro.build). После перехода сайта на Astro папка `docs/` целиком
переезжает в `src/content/docs/`, при этом `en/` станет корнем, а `ru/` — локалью. Пока сайт
статический, эти файлы никуда не публикуются.

| Страница | ru | en | Статус |
|---|---|---|---|
| Что умеет Drafta | `docs/ru/index.md` | `docs/en/index.md` | готова. Два абзаца ждут решений (TODO в тексте): ревизии и шифрование на диске |
| ИИ-ассистент | `docs/ru/ai-assistant.md` | `docs/en/ai-assistant.md` | готова. Публиковать после исправления падения по ⌘J (аудит A1) |
| MCP-сервер | `docs/ru/mcp-server.md` | `docs/en/mcp-server.md` | `draft: true`, пока `drafta-mcp` не встроен в `.app` и не открывает зашифрованную библиотеку |

Факты сверены с кодом `Drafta@9d3e82d`, источники перечислены в `Drafta/docs/audit/2026-09-24/`.
Если меняется поведение приложения, правьте обе локали сразу. Комментарии `<!-- TODO -->`
отмечают места, где текст зависит от ещё не принятых решений.

Выносы вида `> [!NOTE]` Starlight отрисует, если включить плагин
`remark-github-admonitions-to-directives`. Второй вариант — переписать их в синтаксис `:::note`.
