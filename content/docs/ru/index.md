Drafta — нативный Markdown-редактор заметок для macOS. Он сделан для программистов, у которых в
заметках код, диаграммы и формулы. Приложение написано на Swift и SwiftUI. Внутри работает редактор
CodeMirror 6, так что это не Electron.

**Требования:** macOS 26.4 или новее.

## Редактор

- Подсветка синтаксиса больше чем для 50 языков — как в редакторе, так и в превью.
- Три режима: только текст, только превью и split. В split прокрутка синхронная.
- Превью показывает:
  - GFM-таблицы, списки задач и сноски;
  - блоки-выноски `> [!NOTE]`, `[!TIP]`, `[!WARNING]`, `[!IMPORTANT]`, `[!CAUTION]`;
  - диаграммы **Mermaid** и формулы **KaTeX** (`$…$`, `$$…$$`);
  - wiki-ссылки `[[Название заметки]]`.
- Таблицы: размер выбирается сеткой, Tab переходит по ячейкам, есть панель инструментов.
- Slash-команды, сниппеты, автодополнение эмодзи и выносок.
- Закладки на строках, оглавление, граф связей и панель обратных ссылок.
- Типографика при вводе (`--` → `—`), нативная проверка орфографии и пользовательские замены.
- Вставленный форматированный HTML превращается в Markdown. Картинки и файлы можно вставить или
  перетащить — они становятся вложениями заметки.

## Библиотека

- Блокноты с любой глубиной вложенности, заметки перетаскиваются между ними.
- Теги:
  - берутся из текста (`#tag`, вложенные через `/`: `#drafta/export`);
  - добавляются вручную;
  - у каждого тега свой цвет.
- Статусы: Active, On Hold, Completed, Dropped.
- Закреплённые, недавние и шаблоны. Корзина с автоочисткой: никогда, через 7, 30 или 90 дней.
- Quick Open (⌘P) — нечёткий поиск по заметкам, тегам и блокнотам.
- Любую заметку можно открыть в отдельном окне.

## Хранение и синхронизация

Каждая заметка — отдельный файл `.md` с YAML front-matter. Ревизии и вложения лежат рядом в папке
библиотеки.

Синхронизация между компьютерами Mac:

| Вариант | Что это |
|---|---|
| **Drafta cloud** | Хранилище через аккаунт Drafta, входит в тариф |
| **Свой CouchDB 3.x** | Ваш сервер: локальный или удалённый, без квот |

Заметки шифруются на Mac до отправки (AES-256-GCM), поэтому сервер хранит только шифротекст.
Синхронизация запускается при старте приложения и через несколько секунд после правки.

## Экспорт и импорт

- **Экспорт:** PDF, DOCX, HTML и Markdown. Можно экспортировать одну заметку или несколько сразу в
  ZIP.
- **Профили оформления:** Clean, Developer и Academic, плюс свои. Настраиваются размер страницы,
  поля, колонтитулы, титульная страница и оглавление.
- **Импорт:** файлы `.md` (относительные картинки копируются во вложения) и `.html` в формате экспорта
  Bear.
- **Резервная копия:** вся библиотека в ZIP (⇧⌘B) и автобэкап по расписанию.

## Оформление

- 11 встроенных тем:
  - светлые: Vellum и Default Light;
  - тёмные: Graphite & Ochre, Fjord, Phosphor, Amethyst Glass, Default Dark, Drafta Dark, Dark
    Islands, Tokyo Night и Solarized Dark.
- Свои темы в JSON: редактор тем, импорт и экспорт.
- Пресеты типографики: шрифты текста, заголовков и кода, размер и интерлиньяж.
- Горячие клавиши форматирования переназначаются в **Settings → Keybindings**.

## ИИ

- **[ИИ-ассистент](./ai-assistant/)** (⌘J) переписывает выделение или дописывает текст у курсора.
  Работает через ваш ключ Anthropic, OpenAI или DeepSeek.
- **[MCP-сервер](./mcp-server/)** даёт ИИ-агентам — Claude Code, Claude Desktop, Cursor, Zed, Codex —
  искать, читать и вести вашу библиотеку.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌘N / ⇧⌘N | Новая заметка / новая из шаблона |
| ⌘P | Quick Open |
| ⌘F | Поиск и замена в заметке |
| ⌘J | ИИ-ассистент |
| ⌥⌘L | Показать или скрыть список заметок |
| ⌥⌘B | Все закладки |
| ⇧⌘E | Экспорт |
| ⌘B / ⌘I / ⌘K | Жирный / курсив / ссылка |
| ⌘1 – ⌘3 | Заголовки H1–H3 |
| ⇧⌘L / ⇧⌘O / ⇧⌘X | Маркированный / нумерованный список / список задач |
| ⌥↑ / ⌥↓ | Переместить строку |
| ⌘, | Настройки |
