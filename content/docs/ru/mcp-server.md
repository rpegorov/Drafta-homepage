[Model Context Protocol](https://modelcontextprotocol.io) (MCP) — открытый протокол, по которому
ИИ-агенты получают доступ к внешним данным и инструментам. В Drafta есть MCP-сервер `drafta-mcp`.
Если подключить его к агенту, агент работает с вашей библиотекой заметок как с базой знаний.

## Зачем это нужно

- **Контекст для кода.** Claude Code или Cursor находят ваши заметки об архитектуре, решениях и
  грабли проекта и читают их, прежде чем менять код.
- **Журнал работы.** Агент дописывает в заметку итоги сессии, меняет статус задачи и ставит теги.
- **Черновики.** Агент создаёт новую заметку в нужном блокноте, в Markdown, который Drafta
  отрисует: с диаграммами Mermaid, формулами, выносками и списками задач.
- **Поиск по базе знаний.** Можно спросить ассистента в Claude Desktop, что вы писали про
  какую-то тему, и он найдёт заметки.

Сервер работает локально и общается с агентом через stdin/stdout. Никаких сетевых портов он не
открывает. Заметки читаются и пишутся прямо в папке библиотеки. Если Drafta в это время открыта,
изменения появляются в ней сразу.

## Где взять сервер

Сервер поставляется внутри приложения:

```
/Applications/Drafta.app/Contents/Helpers/drafta-mcp
```

### Параметры запуска

| Флаг | Что делает |
|---|---|
| `--library <путь>`, `-l <путь>` | Папка библиотеки. По умолчанию `~/Library/Application Support/Drafta/Library`. Путь указывайте полностью: `~` не раскрывается |
| `--read-only`, `-r` | Режим только чтения: инструменты записи скрываются от агента |

> [!TIP]
> Начните с `--read-only`. Права на запись включайте, когда увидите, как агент работает с
> заметками.

## Подключение

### Claude Code

```sh
# только чтение, для всех проектов
claude mcp add --scope user drafta -- /Applications/Drafta.app/Contents/Helpers/drafta-mcp --read-only

# чтение и запись
claude mcp add --scope user drafta -- /Applications/Drafta.app/Contents/Helpers/drafta-mcp
```

Проверка: команда `claude mcp list` или `/mcp` внутри сессии.

### Claude Desktop

Файл `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "drafta": {
      "command": "/Applications/Drafta.app/Contents/Helpers/drafta-mcp",
      "args": ["--read-only"]
    }
  }
}
```

После сохранения перезапустите Claude Desktop.

### Cursor

Файл `~/.cursor/mcp.json` для всех проектов или `.cursor/mcp.json` для одного. Формат тот же, что у
Claude Desktop.

### Zed

В `settings.json`:

```json
{
  "context_servers": {
    "drafta": {
      "command": "/Applications/Drafta.app/Contents/Helpers/drafta-mcp",
      "args": ["--read-only"]
    }
  }
}
```

### Codex CLI

Файл `~/.codex/config.toml`:

```toml
[mcp_servers.drafta]
command = "/Applications/Drafta.app/Contents/Helpers/drafta-mcp"
args = ["--read-only"]
```

> [!NOTE]
> Форматы конфигурации задают сами клиенты, и они меняются. Если пример не сработал, сверьтесь с
> документацией клиента.

## Инструменты

### Чтение

Эти инструменты доступны всегда.

| Инструмент | Параметры | Что делает |
|---|---|---|
| `search_notes` | `query`, `tag`, `status`, `notebook`, `limit` (по умолчанию 20, максимум 100) | Ищет подстроку в заголовке, тексте и тегах, без учёта регистра. Новые заметки первыми, корзина не входит. Пустой `query` возвращает последние заметки |
| `read_note` | `note` — UUID или заголовок | Возвращает полный текст заметки с заголовком, id, тегами и датой правки |
| `list_notebooks` | — | Дерево блокнотов с UUID |
| `list_tags` | — | Все теги библиотеки |
| `formatting_guide` | — | Шпаргалка по Markdown, который отрисовывает Drafta |

### Запись

Эти инструменты скрыты в режиме `--read-only`.

| Инструмент | Параметры | Что делает |
|---|---|---|
| `create_note` | `title`*, `content`*, `notebook`, `tags`, `status` | Создаёт заметку. Без блокнота заметка попадает в Inbox |
| `append_to_note` | `note`*, `text`* | Дописывает текст в конец заметки |
| `update_note` | `note`*, `content`* | Заменяет текст целиком |
| `set_note_status` | `note`*, `status`* | Меняет статус: `active`, `onHold`, `completed`, `dropped`, `none` |
| `tag_note` | `note`*, `tags`* | Добавляет теги |
| `create_notebook` | `name`*, `parent` | Создаёт блокнот. Если такой уже есть, возвращает существующий |
| `trash_note` | `note`* | Переносит заметку в корзину. Файл сохраняется |

\* — обязательный параметр. Блокнот можно указать по имени или по UUID.

Перед `append_to_note` и `update_note` прежний текст сохраняется в историю ревизий, так что любую
правку агента можно откатить.

### Ресурсы

Сервер отдаёт до 200 последних заметок как ресурсы `drafta://note/<UUID>` с типом `text/markdown`.
Клиенты, которые умеют прикреплять ресурсы (например, Claude Desktop), могут подложить заметку в
контекст без вызова инструмента.

## Совместная работа с приложением

- Приложение следит за папкой библиотеки и подхватывает правки агента на лету.
- Бывает, что агент меняет заметку, в которой у вас есть несохранённый текст. Тогда Drafta
  предложит выбор:
  - **Reload** — взять версию с диска;
  - **Keep mine** — оставить свой текст.
- Правки агента синхронизируются с другими Mac как обычные изменения.
- Сервер работает и без запущенного приложения.

## Безопасность

- Агент с правами записи может переписать или удалить в корзину любую заметку. Если нужна только
  справка, используйте `--read-only`.
- Всё, что агент прочитал, уходит провайдеру его модели на тех условиях, которые у вас с этим
  провайдером.
- Сервер работает под вашим пользователем, в сеть не выходит и портов не открывает.

## Ограничения

- Пока нет инструментов, чтобы:
  - снять тег;
  - перенести заметку в другой блокнот;
  - восстановить заметку из корзины;
  - прочитать историю ревизий;
  - работать с вложениями.
- `search_notes` ищет по подстроке, а не так, как поиск в приложении.
- `list_notebooks` показывает два уровня вложенности.
