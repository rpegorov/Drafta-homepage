Ассистент работает прямо в тексте заметки. Он переписывает выделенный фрагмент или вставляет новый
текст у курсора. Ответ появляется в тексте, пока модель его печатает. Дальше вы решаете: принять
его или отклонить.

Drafta не продаёт доступ к моделям. Ассистент ходит к провайдеру напрямую через **ваш API-ключ**.

## Настройка

1. Откройте **Settings → AI**.
2. В разделе **Provider** выберите активного провайдера: **Claude**, **OpenAI** или **DeepSeek**.
3. В разделе нужного провайдера вставьте ключ и нажмите **Save**.
4. Нажмите **Test**, чтобы проверить ключ. Проверка отправляет крошечный запрос и стоит пару токенов.

Провайдера можно переключать в любой момент, сохранённые ключи при этом не теряются.

| Провайдер | Модель |
|---|---|
| Claude (Anthropic) | `claude-haiku-4-5` |
| OpenAI | `gpt-4o-mini` |
| DeepSeek | `deepseek-chat` |

Модели выбраны за скорость: ассистент нужен для коротких правок в тексте.

## Как пользоваться

1. Выделите текст, если хотите его изменить. Если хотите вставить новый текст, просто поставьте
   курсор.
2. Нажмите **⌘J**.
3. Выберите пресет или напишите свой запрос и нажмите **Enter**.
4. Когда ответ готов:

| Действие | Как |
|---|---|
| Принять | **Accept**, **⌘↩** или клик в редакторе |
| Отклонить | **Reject** или **Esc** |
| Сгенерировать заново | **⌘R** |
| Отменить во время генерации | **Esc** |

### Пресеты

| Пресет | Нужно выделение | Что делает |
|---|---|---|
| Improve writing | да | Улучшает стиль и грамматику, сохраняя язык и Markdown |
| Make shorter | да | Сокращает, оставляя главное |
| Make longer | да | Раскрывает подробнее, с примерами |
| Fix grammar | да | Исправляет только грамматику и орфографию |
| Summarize | нет | Пересказывает выделение или текст выше в 1–3 пунктах |
| Continue writing | нет | Продолжает текст в том же тоне |
| Generate diagram | нет | Возвращает диаграмму в блоке ` ```mermaid ` |
| Custom prompt | нет | Выполняет ваш запрос из поля ввода |

## Какие данные уходят провайдеру

Запрос отправляется только тогда, когда вы его запускаете, и только выбранному провайдеру. Серверы
Drafta в этом не участвуют, телеметрии нет.

**Отправляется:**
- инструкция пресета или ваш запрос;
- заголовок заметки;
- выделенный текст;
- до двух абзацев до и после выделения, всего не больше примерно 32 000 символов.

**Не отправляется:** остальной текст заметки, другие заметки, вложения, теги и метаданные.

> [!IMPORTANT]
> Провайдер получает этот фрагмент открытым текстом. Шифрование библиотеки на запросы к ИИ не
> распространяется. Не запускайте ассистент на фрагментах, которые нельзя показывать третьей стороне.

## Где хранятся ключи

Ключи лежат в связке ключей macOS (Keychain) и читаются только в момент запроса. В логах
приложения ключи маскируются.

- **Посмотреть:** в настройках показывается только начало и конец ключа.
- **Заменить:** кнопка **Replace**.
- **Удалить:** кнопка **Remove**.

## Ошибки

| Сообщение | Что сделать |
|---|---|
| *No API key set for …* | Добавьте ключ в Settings → AI |
| *Invalid API key* | Проверьте ключ или замените его |
| *Rate limited — try again in N s* | Провайдер ограничил частоту запросов. Подождите |
| *Server returned …* | Ошибка на стороне провайдера. Текст ответа показан в сообщении |

## Ограничения

- Длина ответа ограничена 2000 токенами. Очень длинные фрагменты лучше переписывать частями.
- Выбрать другую модель в интерфейсе пока нельзя.
