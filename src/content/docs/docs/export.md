Open **Export…** (⇧⌘E) and pick a format:

- PDF
- DOCX
- HTML
- Markdown

Local images come along as attachments.

## Profiles

Three profiles set the look of the result: **Clean**, **Developer** and **Academic**.

## Import

Drafta imports `.md` and `.html` (Bear format).

Export needs a plan: in read-only mode after the trial it is unavailable — see [Account and trial](/docs/account/).
