## Built-in themes

Eleven themes ship with the app. Five signature ones:

- Graphite & Ochre
- Vellum
- Fjord
- Phosphor
- Amethyst Glass

And six more:

- Default Light
- Default Dark
- Drafta Dark
- Dark Islands
- Tokyo Night
- Solarized Dark

## Your own theme

A JSON theme of your own drops straight in.
