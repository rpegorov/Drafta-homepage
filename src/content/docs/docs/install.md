## Requirements

macOS 26 or later, on Apple Silicon or Intel. Drafta is a native Swift and SwiftUI app — not a web app and not an Electron shell.

## Install

1. Download the DMG from the latest release.
2. Open it and drag **Drafta.app** into **Applications**.

## First launch

The build is not notarised yet, so macOS blocks the first launch. To allow it:

1. Open **System Settings → Privacy & Security**.
2. Scroll to the message about Drafta and click **Open Anyway**.
3. Confirm.

macOS asks only once. Notarisation, which removes this step, is in progress.

## Updates

Updates arrive by themselves: Sparkle checks once a day. **Drafta → Check for Updates…** checks on demand.
