---
title: Keyboard shortcuts
description: The main Drafta shortcuts — new note, quick open, search, assistant, note list, export and headings.
sidebar:
  order: 8
---

| Shortcut | Action |
|---|---|
| ⌘N | New note |
| ⌘P | Quick open: fuzzy search across every note |
| ⌘F | Search |
| ⌘J | Open the assistant |
| ⌥⌘L | Show or hide the note list |
| ⇧⌘E | Export |
| ⌘1 – ⌘3 | Heading 1, 2, 3 |

The three view modes — editor, preview and split — switch with a click; there is no keyboard shortcut for them.
