Drafta is a native Markdown editor for macOS. Every note is a plain `.md` file with YAML front-matter on your disk; an encrypted copy syncs through your Drafta account or your own CouchDB.

- [Install](/docs/install/) — the DMG and the first launch.
- [Account and trial](/docs/account/) — why there are two passwords.
- [Sync](/docs/sync/) — Drafta cloud or your own CouchDB.
- [Encryption](/docs/encryption/) — what the server can and cannot see.
- [MCP server](/docs/mcp/) — Claude and other MCP clients in your library.
- [AI assistant](/docs/ai/) — ⌘J with your own API key.
- [Themes](/docs/themes/) — eleven built in, or your own JSON theme.
- [Keyboard shortcuts](/docs/shortcuts/)
- [Export](/docs/export/) — PDF, DOCX, HTML and Markdown.
