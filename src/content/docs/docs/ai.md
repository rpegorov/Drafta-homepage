The assistant opens on **⌘J**. It uses the provider you bring an API key for:

| Provider | Model |
|---|---|
| Anthropic | `claude-haiku-4-5` |
| OpenAI | `gpt-4o-mini` |
| DeepSeek | `deepseek-chat` |

Keys are stored in the macOS Keychain.

To give an external assistant such as Claude access to your library, use the [MCP server](/docs/mcp/).
