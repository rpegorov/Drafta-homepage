MCP-сервер встроен в приложение — ставить ничего не нужно. Он даёт Claude и другим MCP-клиентам 12 инструментов для всей библиотеки.

## Инструменты

Чтение:

- `search_notes` — искать заметки
- `read_note` — читать заметку
- `list_notebooks` — список блокнотов
- `list_tags` — список тегов
- `formatting_guide` — справка по форматированию

Запись:

- `create_note` — создать заметку
- `append_to_note` — дописать в заметку
- `update_note` — переписать заметку
- `set_note_status` — сменить статус заметки
- `tag_note` — поставить тег
- `create_notebook` — создать блокнот
- `trash_note` — отправить заметку в корзину

Когда ассистент переписывает заметку, прежний текст сохраняется ревизией.

## Режим только для чтения

Нужен ассистент, который только смотрит? Запустите сервер в режиме только для чтения — инструменты записи исчезнут.
