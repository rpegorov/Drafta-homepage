## Сквозное шифрование синхронизации

Заметки шифруются алгоритмом **AES-256-GCM** на вашем Mac до отправки — ключом, который получается из пароля библиотеки через **PBKDF2-HMAC-SHA256**. Сервис хранит шифротекст, ключа у него нет.

## Что видит сервер

- почту аккаунта и тариф;
- по каждой заметке: её id, время последнего изменения и размер зашифрованных данных.

Заголовок, текст, теги и вложения остаются шифротекстом.

## Граница

Шифрование защищает путь синхронизации, а не ваш диск. Библиотека на Mac остаётся обычными Markdown-файлами — `grep`, git и другие редакторы продолжают работать. Сам диск защищает FileVault.

## Пароль библиотеки

Ключ получается из пароля библиотеки, который не покидает ваш Mac. Сбросить его за вас не сможет никто — см. [Аккаунт и триал](/ru/docs/account/).
