## Требования

macOS 26 или новее, Apple Silicon или Intel. Drafta — нативное приложение на Swift и SwiftUI, не веб-приложение и не оболочка Electron.

## Установка

1. Скачайте DMG из последнего релиза.
2. Откройте его и перетащите **Drafta.app** в **Applications**.

## Первый запуск

Сборка пока не нотаризована, поэтому macOS заблокирует первый запуск. Чтобы разрешить его:

1. Откройте **«Системные настройки» → «Конфиденциальность и безопасность»**.
2. Пролистайте до сообщения о Drafta и нажмите **«Всё равно открыть»**.
3. Подтвердите.

macOS спросит только один раз. Нотаризация, которая уберёт этот шаг, в работе.

## Обновления

Обновления приходят сами: Sparkle проверяет их раз в сутки. **Drafta → Check for Updates…** проверяет по требованию.
