---
title: Горячие клавиши
description: Основные сочетания Drafta — новая заметка, быстрый переход, поиск, ассистент, список заметок, экспорт и заголовки.
sidebar:
  order: 8
---

| Сочетание | Действие |
|---|---|
| ⌘N | Новая заметка |
| ⌘P | Быстрый переход: нечёткий поиск по всем заметкам |
| ⌘F | Поиск |
| ⌘J | Открыть ассистента |
| ⌥⌘L | Показать или скрыть список заметок |
| ⇧⌘E | Экспорт |
| ⌘1 – ⌘3 | Заголовок 1, 2, 3 |

Три режима просмотра — редактор, превью и split — переключаются кликом; сочетания клавиш для них нет.
