## Встроенные темы

В приложении одиннадцать тем. Пять фирменных:

- Graphite & Ochre
- Vellum
- Fjord
- Phosphor
- Amethyst Glass

И ещё шесть:

- Default Light
- Default Dark
- Drafta Dark
- Dark Islands
- Tokyo Night
- Solarized Dark

## Своя тема

Свою тему в формате JSON можно добавить сразу.
