Ассистент открывается по **⌘J**. Он работает с тем провайдером, для которого у вас есть API-ключ:

| Провайдер | Модель |
|---|---|
| Anthropic | `claude-haiku-4-5` |
| OpenAI | `gpt-4o-mini` |
| DeepSeek | `deepseek-chat` |

Ключи хранятся в связке ключей macOS (Keychain).

Чтобы дать доступ к библиотеке внешнему ассистенту, например Claude, используйте [MCP-сервер](/ru/docs/mcp/).
