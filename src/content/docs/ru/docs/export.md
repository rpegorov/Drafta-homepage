Откройте **Export…** (⇧⌘E) и выберите формат:

- PDF
- DOCX
- HTML
- Markdown

Локальные изображения переносятся вложениями.

## Профили

Три профиля задают вид результата: **Clean**, **Developer** и **Academic**.

## Импорт

Drafta импортирует `.md` и `.html` (формат Bear).

Экспорт требует тарифа: в режиме только для чтения после триала он недоступен — см. [Аккаунт и триал](/ru/docs/account/).
