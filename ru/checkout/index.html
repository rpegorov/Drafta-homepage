Оплата

Выберите тариф для аккаунта

Каждый новый аккаунт начинается с 30-дневного пробного периода — карта не нужна. Когда он закончится, аккаунт продолжит работу на выбранном здесь тарифе. Drafta — нативное приложение для macOS, а заметки остаются обычными файлами Markdown на диске.

30 дней полного приложения, без карты

Регистрация запускает 30-дневный пробный период: полное приложение, и пока он идёт, списаний нет. После него аккаунт продолжает работу на тарифе, выбранном ниже.

Тарифы

Один тариф — всё включено.

Оплата раз в месяц или раз в год для одного и того же приложения; цены читаются напрямую из api.drafta.org при открытии страницы — ни одна цена здесь не зашита в разметку.

Облачное хранилище зашифровано end-to-end, поэтому сервис хранит шифротекст, который не может прочитать. Если не хотите тратить квоту тарифа, подключите собственный CouchDB — локально или на сервере, который вы контролируете.

Платёжный провайдер ещё не подключён: деньги не списаны, покупка не завершена. Строки выше — ответ сервера без изменений.

Войти

Как оплата работает сейчас

1
Выберите тариф

Тариф и два периода оплаты читаются из API аккаунтов при загрузке страницы. Если API недоступен, страница покажет тот же тариф из конфигурации сайта — но никогда другие цены.

2
Для покупки нужна сессия

Нужен токен доступа, который записывает страница входа. Без него страница отправит вас войти и сразу вернёт обратно.

3
Сервер отвечает — страница повторяет

Выбранный тариф уходит в API аккаунтов, а ответ — тариф, статус, конец периода — печатается выше ровно в том виде, в каком пришёл. Оплата картой ещё не подключена, поэтому страница никогда не сообщает о завершённой покупке сама.

Вопросы

Можно уже оплатить картой?
Пока нет. Платёжный провайдер не подключён: подписка фиксирует запрос в аккаунте, а страница показывает ответ сервера без изменений. Деньги не списываются.
Есть ли тариф дешевле?
Нет. Тариф один, а периодов оплаты два — месяц и год; второго тарифа и пожизненной лицензии нет. Квота хранилища и заметок в обоих случаях одна и та же, и она читается из API аккаунтов.
Что будет после пробного периода?
30 дней начинаются с момента регистрации и не требуют карты. После них на аккаунте действует тариф, выбранный на этой странице.
Что нужно приложению?
macOS 26.4, Apple Silicon и Intel. Приложение скачивается со страницы релизов — это не веб-приложение.
